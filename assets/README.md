## UI Screenshot Specifications & Standards

When capturing or updating application previews:

1. **Resolution & Viewport:**
   - Standard 1080p desktop viewport ($1920 \times 1080\text{ px}$) or high-DPI browser capture.
   - Maintain a minimum resolution of $1280 \times 720\text{ px}$.
2. **Format & Compression:**
   - Use `.png` or `.webp` for vector/interface graphics, and high-quality `.jpg` / `.png` for full-page screenshots.
   - Recommended maximum file size per static image: $< 400\text{ KB}$.
3. **Animated GIFs / Short Videos:**
   - If adding interaction GIFs (e.g., `demo.gif`), cap framerate at $24\text{ fps}$ and duration $\le 15\text{ seconds}$ to maintain fast repository cloning and loading times.
4. **Theme Consistency:**
   - Ensure screenshots reflect the official Streamlit corporate dark theme with Rash Rolamentos brand styling.
